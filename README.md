# Close Call Desk — میز معاملات دستی

یک صفحهٔ وب محلی برای شرکت **دستی** در مسابقهٔ
[technocore-close-call-challenge](https://github.com/flop-labs/technocore-close-call-challenge)
(اتاق `close1` روی [technocore.chat](https://technocore.chat)).

با این صفحه می‌توانی بدون دستور خطی:

- کلید بازیکن (`did:key` / Ed25519) بسازی یا وارد کنی
- ثبت‌نام کنی و **۱۰,۰۰۰ POLF** بگیری
- با دکمه‌های **خرید / فروش** پیشنهاد (Maker) بگذاری
- پیشنهاد بقیه را بررسی و **قبول (Taker)** کنی
- قیمت زندهٔ NVDA، مرجع داور و محدودهٔ ±۵٪ را ببینی
- تراکنش‌ها و وضعیت تسویه/باطل شدن را دنبال کنی

همهٔ امضاها **روی سیستم خودت** انجام می‌شود؛ سرور فقط به `technocore.chat`
و `api.hyperliquid.xyz` وصل می‌شود و فقط روی `localhost` بالا می‌آید.

> ⚠️ قوانین مسابقه هنوز **draft** است؛ تا FLOP Labs رکورد launch را امضا و
> منتشر نکند چیزی رسمی نیست. قبل از ثبت‌نام واقعی، پست launch record را چک کن.

## نیازمندی‌ها

- Python **3.10 یا جدیدتر** (تست‌شده با 3.12)
- پکیج `cryptography` (تنها وابستگی)
- اینترنت (برای خواندن اتاق‌ها و قیمت)

## اجرا

### ویندوز
روی `start.bat` دوبار کلیک کن (سرور بالا می‌آید و مرورگر باز می‌شود).

### همهٔ سیستم‌ها
```bash
git clone https://github.com/Defarhad/closecall-desk.git
cd closecall-desk
pip install -r requirements.txt
python server.py --open        # بدون --open هم می‌شود، بعد دستی مرورگر را باز کن
```

صفحه: **http://127.0.0.1:8777/**

برای توقف: کلید `Ctrl+C` در ترمینال، یا بستن پنجرهٔ `start.bat`.

## راهنمای سریع (تب‌ها)

1. **راه‌اندازی**
   - «ساخت کلید جدید» → `did:key` و seed را یک‌جا ذخیره کن.
   - «ثبت‌نام owner» → پیام امضاشده در اتاق `close1` می‌رود؛ در sweep بعدی
     (هر ۵ دقیقه) ۱۰,۰۰۰ POLF می‌گیری. وضعیت با پیل «mint شد ✓» مشخص می‌شود.
2. **معامله**
   - دکمهٔ سبز **خرید** یا قرمز **فروش**، تعداد (حداقل `0.1`) و قیمت را بده.
   - قیمت باید داخل محدودهٔ ±۵٪ مرجع باشد؛ صفحه جلوی ارسالِ خارج از محدوده را می‌گیرد.
   - «انتشار پیشنهاد» = پیام `t:trade` با امضای maker و `taker: "any"`.
   - «قبول پیشنهاد» = JSON پیشنهاد را بچسبان (یا از جدول «قبول» بزن) → امضای
     سازنده اول بررسی می‌شود → بعد countersign و ارسال.
3. **تابلو**: مرجع داور، global price، جدول pnl/positions/state و flow اخیر.
4. **تراکنش‌ها**: تریدهای شما + وضعیت (تسویه/باطل/باز) + گزارش عملیات محلی.
5. **اتاق‌ها**: مشاهدهٔ خام هر اتاق + ارسال پیام امضاشدهٔ آزاد.

## اتاق‌ها

- `close1` — اتاق رسمی و همیشه‌فعال (پیش‌فرض).
- اتاق‌های داور (فقط داور می‌نویسد): `d-close1-price`، `d-close1-flow`،
  `d-close1-pnl`، `d-close1-positions`، `d-close1-state`.
- فقط اتاق‌های **ثبت‌شده** نزد داور حساب می‌شوند؛ پیام اتاق ثبت‌نشده در flow با
  `unlisted` علامت می‌خورد و رد می‌شود.

## امنیت — مهم

- کلید خصوصی (seed) در `state.json` کنار `server.py` ذخیره می‌شود. **این فایل را
  آنلاین آپلود نکن، در گیت نگذار (در `.gitignore` هست) و کپی‌اش نده.** هرکس seed
  را داشته باشد حساب مسابقهٔ تو را دارد.
- سرور فقط روی `127.0.0.1` گوش می‌دهد؛ آن را عمومی نکن.
- برای شرکت واقعی، کلیدی را که در گفتگو یا اسکرین‌شات داده‌ای دوباره استفاده نکن؛
  همیشه از داخل صفحه کلید تازه بساز.
- پیام‌های اتاق‌ها عمومی است؛ هرگز متنی که کلید/رمز دارد در اتاق نفرست.

## خلاصهٔ API (سرور محلی)

| مسیر | کار |
|---|---|
| `GET /` | صفحهٔ UI |
| `GET /api/state` | کلید، sweep فعلی، شمارشگرها، گزارش محلی |
| `GET /api/hl` | قیمت زندهٔ کندل ۱ دقیقه‌ای `xyz:NVDA` |
| `GET /api/room/<room>?limit=` | پروکسی خواندن اتاق از technocore.chat |
| `POST /api/key/new` \| `import` \| `export` | ساخت/ورود/خروجی کلید |
| `POST /api/register` | پیام `owner` (ثبت‌نام + mint) |
| `POST /api/offer` | ساخت terms + امضای maker + انتشار |
| `POST /api/inspect` | بررسی امضای maker بدون ارسال |
| `POST /api/accept` | countersign توسط taker + انتشار ترید |
| `POST /api/post` | هر پیام امضاشدهٔ دلخواه |

## عیب‌یابی

- **پورت 8777 اشغال است:** پنجرهٔ قبلی `start.bat` را ببند، یا `server.py` را ویرایش
  کن و پورت را عوض بده.
- **پاسخ 429 از technocore.chat:** محدودیت نرخ (۱۲۰ خواندن و ۳۰ نوشتن در دقیقه
  به ازای هر IP). صفحه خودش آهسته poll می‌کند؛ چند لحظه صبر کن.
- **پیام تکراری (422):** technocore.chat متن‌های تکراریِ اخیر را رد می‌کند؛ مقداری
  تغییر بده.
- **«mint شد» نمی‌بینی:** تا sweep بعدی (حداکثر ۵ دقیقه) طول می‌کشد؛ در
  `d-close1-flow` باید کلیدت در `mints` بیاید.
- **وضعیت ترید «نامشخص» ماند:** صفحه فقط ۳ sweep اخیر flow و ۱۰۰ پیام اخیر
  `close1` را می‌خواند؛ flow گاهی لیست‌های بلند را کوتاه می‌کند (`omitted`).
